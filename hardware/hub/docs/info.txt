
Productnaam: 		RadioBerry Hub 2350
Korte naam op PCB: 	RB Hub 2350
Ondertitel:			RP2350 Ethernet hub for RadioBerry SDR and Radio control



The RadioBerry Hub 2350 is an RP2350-based Ethernet and USB-C host/controller board for the RadioBerry ecosystem. 
It can act as a standalone host for the RadioBerry SDR card and as a control hub for radio controller applications.



Het idee onstond bij het bekijken van een interessant project genaamd 'μSDR–Pico' van Arjan te Marvelde.

Ik zag een leuk ecosystem ontstaan rondom de radioberry. 

Het eerste idee is om de raspberry pi te vervangen door de RadioBerry Hub 2350. 
De microcontroller rp2350 zorgt voor laden van de gateware en implementeert het openhpsdr protocol-1 om de  radio
operationeel te krijgen via de ethernet (100Mb) optie.

Een ander idee is om via de connector op de achterkant een board te plaatsen die zorgt voor de audio,
mic in en audio uit maar ook de mogelijkheid voor een paar knoppen en een bijbehorend display zoals Arjan dit
voor zijn project heeft gedaan.

Verder moet de hub ook gebruikt kunnen worden om andere radio functies, zoals een Power amplifier controller, te kunnen maken.


Kortom voldoende inspiratie voor een aantal leuke software/ hardware projecten op basis van deze nieuwe radioberry hub 2350 module.
